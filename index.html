PyString v1 Documentation


PyString is a very simple Python library for working with strings. It is created by TheSimpleProgrammer9999.

rmvStr()

rmvStr() has 2 parameters: string and index. It removes a character from string. The character is
defined by index. But the index does not start at zero(like lists in most prgramming languages),
it starts at one.(This also applies to other PyString functions that contains an index parameter.)

Example code:

rmvStr(string = "Hello World!", index = 1)

addStr()

addStr() has 3 parameters: string, index, and strToAdd. It adds strToAdd into string at index.

Example code:

addStr(string = "Hello World!", index = 13, strToAdd = " How's it going?")

getPartOf()

getPartOf() has 2 parameters: string and index. It gets part of string at index.

Example code:

getPartOf(string = "Hi guys!", index = 2)

scribble()

scribble() has 1 parameter: string. It scrambles letters in string.

Example code:

scribble("Scribble me!")

thinkUpWord()

thinkUpWord() returns a random word. It has no parameters.

Example code(it's obvious):

thinkUpWord()
